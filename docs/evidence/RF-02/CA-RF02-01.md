# Evidencia de CA-RF02-01

## Alcance verificado

CA-RF02-01 verifica que un visitante puede solicitar el detalle de un producto
disponible y recibir sus metadatos técnicos y una oferta de licencia activa.

La prueba crea una categoría, un producto, un tipo de licencia y una oferta
activos. Configura un nombre ficticio para `preview_file` solo como
precondición y no crea ni publica ningún archivo.

## Ciclo test-first observado

### RED

Con PostgreSQL disponible, se ejecutó:

```bash
.venv/bin/python -m pytest apps/catalog/tests/test_views.py::test_product_detail_displays_technical_metadata_and_active_license_offer -q
```

La prueba falló con `assert 404 == 200` al solicitar
`GET /catalog/nocturnos-urbanos/`. El fallo confirmó que la ruta de detalle no
existía todavía.

### GREEN

Después de registrar la ruta, resolver el producto desde
`get_available_products()` y representar los campos públicos, se ejecutó el
mismo comando.

Resultado observado: `1 passed in 0.45s`.

## Puerta de calidad

Se verificaron Django, migraciones, Ruff, dependencias y el diff sin errores.
La regresión completa finalizó con `18 passed in 0.94s`.

## Alcance excluido

Esta evidencia no verifica el reproductor ni la URL de preview, productos no
disponibles, exclusión específica de ofertas inactivas, ausencia de preview ni
la privacidad del archivo maestro. Esos comportamientos corresponden a los
demás criterios de RF-02.
