# Evidencia de CA-RF02-03

## Alcance verificado

CA-RF02-03 verifica que `GET /catalog/{slug}/` responde `404` cuando el slug
no existe o el producto no está disponible.

Se añadieron cuatro pruebas HTTP independientes: producto inactivo, categoría
inactiva, producto sin ofertas activas y un slug inexistente sin datos creados.

## Resultado observado

No hubo ciclo RED-GREEN porque el comportamiento ya existía. La vista de
detalle resuelve el producto con `get_object_or_404()` sobre
`get_available_products()`, que excluye productos inactivos.

Las comprobaciones ejecutadas fueron:

```bash
.venv/bin/ruff format apps/catalog/tests/test_views.py
.venv/bin/ruff check apps/catalog/tests/test_views.py
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
.venv/bin/python -m pytest apps/catalog/tests/test_views.py::test_product_detail_returns_404_for_an_unknown_slug -q
.venv/bin/python -m pytest apps/catalog/tests/test_views.py::test_product_detail_returns_404_for_an_inactive_category apps/catalog/tests/test_views.py::test_product_detail_returns_404_without_an_active_license_offer -q
```

Resultados observados: `11 passed in 0.65s` para el archivo de vistas y
`1 passed in 0.43s` para el caso de slug inexistente. Los dos casos adicionales
finalizaron con `2 passed in 0.48s`.

## Alcance excluido

Esta evidencia no verifica preview, reproducción, ofertas de licencia
inactivas, indisponibilidad de preview ni privacidad del archivo maestro.
