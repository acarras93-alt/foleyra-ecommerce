# Evidencia de CA-RF01-03

## Alcance verificado

CA-RF01-03 verifica que, cuando no hay productos disponibles, un visitante
puede abrir `/catalog/`, recibe una respuesta correcta y ve un mensaje
comprensible de estado vacío.

## Ciclo test-first observado

### RED

Se añadió una prueba HTTP sin crear datos de catálogo y se ejecutó:

```bash
.venv/bin/ruff format apps/catalog/tests/test_views.py
.venv/bin/ruff check apps/catalog/tests/test_views.py
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
```

Ruff no aplicó cambios y su comprobación fue correcta. La prueba focalizada
finalizó con `1 failed, 2 passed`: `/catalog/` respondió `200`, pero la
plantilla renderizó una lista vacía sin el texto requerido.

### GREEN

Se añadió el bloque `{% empty %}` a la lista del catálogo para renderizar
`No hay productos disponibles en este momento.` cuando no hay resultados.

Se ejecutó:

```bash
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
```

Resultado observado: `3 passed`.

## Puerta de calidad

Se ejecutaron las siguientes comprobaciones con resultado correcto:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python manage.py check --database default
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py migrate --check
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/pip check
git diff --check
```

La suite completa finalizó con `10 passed`. Django no detectó incidencias,
cambios de modelo sin migración ni migraciones pendientes; Ruff informó de 57
archivos ya formateados y `pip check` no detectó dependencias incompatibles.

## Alcance excluido

Esta evidencia no verifica paginación, precio mínimo, detalle, API, consultas
N+1, exposición de archivos privados ni los demás criterios de RF-01.
