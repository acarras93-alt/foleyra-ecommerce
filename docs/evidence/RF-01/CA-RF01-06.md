# Evidencia de CA-RF01-06

## Alcance verificado

CA-RF01-06 verifica que, cuando un producto tiene varias ofertas activas, su
tarjeta pública muestra el importe menor con la etiqueta `Desde` y no muestra
un precio ambiguo.

## Ciclo test-first observado

### RED

Se creó un producto disponible con dos ofertas activas: `12.90 EUR` y
`29.90 EUR`. La prueba HTTP solicitó `GET /catalog/` y comprobó que la respuesta
incluyera `Desde 12.90 EUR` y no `Desde 29.90 EUR`.

```bash
.venv/bin/ruff format apps/catalog/tests/test_views.py
.venv/bin/ruff check apps/catalog/tests/test_views.py
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
```

Ruff no aplicó cambios y su comprobación fue correcta. La prueba focalizada
finalizó con `1 failed, 8 passed`: la respuesta fue `200` y contenía el
producto, pero la plantilla no mostraba ningún precio.

### GREEN

El selector anota `minimum_price` mediante el mínimo de
`license_offers__price` filtrado por ofertas activas. La plantilla muestra el
importe anotado con `Desde` y `EUR`.

La primera ejecución tras ese cambio mostró `12,90 EUR` por la localización de
Django. Se aplicó el filtro `unlocalize` al importe para conservar el formato
decimal requerido y se ejecutó:

```bash
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
```

Resultado observado: `9 passed`.

## Regresión y puerta de calidad

Se ejecutaron las siguientes comprobaciones con resultado correcto:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python manage.py check --database default
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py migrate --check
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/pip check
git diff --check
```

La suite completa finalizó con `16 passed`. Django no detectó incidencias,
cambios de modelo sin migración ni migraciones pendientes; Ruff informó de 59
archivos ya formateados y `pip check` no detectó dependencias incompatibles.

## Alcance excluido

Esta evidencia no verifica filtros, ordenación, detalle, API, consultas N+1,
cambios de moneda, archivos privados ni los demás criterios pendientes de
RF-01.
