# Evidencia de CA-RF01-02

## Alcance verificado

CA-RF01-02 verifica que un producto inactivo no aparece en el catálogo público,
aunque su categoría y su oferta de licencia estén activas.

## Prueba existente

La prueba HTTP
`test_catalog_excludes_an_inactive_product_with_an_active_category_and_license_offer`
crea una categoría activa, una oferta activa y un producto con
`is_active=False`. Solicita `GET /catalog/`, comprueba una respuesta `200` y
verifica que el nombre del producto no aparece.

La prueba se añadió en el commit `472ae50` (`test: cover inactive catalog
products`).

## Resultado observado

No hubo un RED artificial. La prueba pasó desde su primera ejecución porque
`get_available_products()` ya filtraba `Product.is_active=True` como parte del
comportamiento implementado para CA-RF01-01. Se registró como cobertura de
comportamiento preexistente y no requirió cambios de producción.

La ejecución focalizada original finalizó con `2 passed`. La comprobación actual
de las vistas del catálogo finalizó con `9 passed`.

## Alcance excluido

Esta evidencia no verifica la desactivación de categorías u ofertas, precio
mínimo, paginación, consultas N+1, detalle, API ni la privacidad del archivo
maestro.
