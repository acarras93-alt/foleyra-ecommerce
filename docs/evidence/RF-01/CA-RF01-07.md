# Evidencia de CA-RF01-07

## Alcance verificado

CA-RF01-07 verifica que cargar categorías y ofertas activas de los productos
disponibles no añade una consulta por cada producto de la página.

## Ciclo test-first observado

### RED

Se creó una prueba de integración con PostgreSQL que construye un producto
disponible, materializa un selector nuevo y accede explícitamente a la categoría
y a `license_offers.all()`. Después crea once productos adicionales fuera del
contador y repite la misma operación con un selector nuevo.

La prueba comprueba que se obtienen 1 y 12 productos, que sus ofertas son
activas y que el número de consultas es constante y no supera tres.

```bash
.venv/bin/ruff format apps/catalog/tests/test_selectors.py
.venv/bin/ruff check apps/catalog/tests/test_selectors.py
.venv/bin/python -m pytest apps/catalog/tests/test_selectors.py -q
```

Ruff no aplicó cambios y su comprobación fue correcta. La prueba focalizada
finalizó con `1 failed`: el número de consultas aumentó de 3 para un producto a
25 para doce, por las cargas diferidas de categoría y ofertas.

### GREEN

El selector incorpora `select_related("category")` y un `Prefetch` de las
ofertas activas. El precio mínimo, filtros de disponibilidad, eliminación de
duplicados y orden existentes se conservaron.

Se ejecutó:

```bash
.venv/bin/ruff format apps/catalog/selectors.py
.venv/bin/ruff check apps/catalog/selectors.py
.venv/bin/python -m pytest apps/catalog/tests/test_selectors.py -q
.venv/bin/python -m pytest apps/catalog/tests/test_views.py -q
```

Resultados observados: la prueba de selectores finalizó con `1 passed` y las
pruebas HTTP del catálogo con `9 passed`.

Una medición adicional contra PostgreSQL, realizada en una transacción revertida,
confirmó 2 consultas tanto para un producto como para doce: una consulta de
productos con categoría y una consulta de ofertas activas precargadas.

## Regresión y puerta de calidad

Se ejecutaron las siguientes comprobaciones con resultado correcto:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python manage.py check --database default
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py migrate --check
.venv/bin/ruff check .
.venv/bin/ruff format --check .
.venv/bin/pip check
git diff --check
```

La suite completa finalizó con `17 passed`. Django no detectó incidencias,
cambios de modelo sin migración ni migraciones pendientes; Ruff informó de 61
archivos ya formateados y `pip check` no detectó dependencias incompatibles.

## Alcance excluido

Esta evidencia no verifica filtros, ordenación, detalle, API, cambios de
moneda, archivos privados ni los demás criterios pendientes de RF-01.
